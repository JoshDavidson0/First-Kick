Costs Only When Called (Pay-Per-Use)
These services cost nothing while idle and only charge on invocation:

Lambda — charged per invocation and duration. Zero calls = zero cost.
Amazon Bedrock — charged per token. No calls = no cost.
API Gateway — charged per request. No requests = no cost.
Secrets Manager API calls — charged per 10,000 API calls. Negligible.


Always-On Costs (Exist Just By Being There)

DynamoDB — you're on pay-per-request (on-demand) billing, so reads/writes cost per operation. However the table itself has no standing charge on on-demand mode. Effectively $0 while idle.
Secrets Manager — charges $0.40 per secret per month just for storing the secret, regardless of usage. You have at least one secret (first-kick/football-data-api-key), so that's ~$0.40/month standing cost.
AWS Amplify — charges for build minutes and hosting. The hosted app has a small standing cost for the SSL certificate and CDN, but it's within free tier limits for low-traffic apps.
CloudWatch — log storage accrues a small cost over time as logs accumulate.


Bottom Line
Your project costs essentially nothing while idle — maybe $0.40-$1/month from Secrets Manager and minimal CloudWatch storage. All significant costs only happen when the app is actively being used.
